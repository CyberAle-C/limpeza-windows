=========================================
LIMPEZA DO WINDOWS
Versão 1.0
=========================================

DESCRIÇÃO
---------
Sistema desenvolvido em Python para remover
arquivos temporários do Windows, liberando
espaço em disco e gerando um relatório da limpeza.

-------------------------------------------------
INSTALAÇÃO
-------------------------------------------------

1. Crie uma pasta em qualquer lugar do computador.

Exemplo:

C:\Projetos\Automacoes

(O nome da pasta pode ser qualquer um. "Automacoes"
é apenas um exemplo.)

2. Coloque TODOS os arquivos do projeto dentro
dessa pasta.

A estrutura deve ficar parecida com esta:

Automacoes/
│
├── main.py
├── limpeza.py
├── relatorio_pc.py
└── README.txt

-------------------------------------------------
REQUISITOS
-------------------------------------------------

- Windows
- Python 3 instalado

-------------------------------------------------
COMO EXECUTAR
-------------------------------------------------

1. Abra o Prompt de Comando como Administrador.

2. Acesse a pasta do projeto.

Exemplo:

cd C:\Projetos\Automacoes

3. Execute o programa:

python main.py

Caso o comando acima não funcione:

py main.py

-------------------------------------------------
OBSERVAÇÕES
-------------------------------------------------

• Alguns arquivos temporários podem permanecer,
pois estão sendo utilizados pelo Windows.

• O relatório será criado automaticamente após
a limpeza.
